# Step 2: Import required libraries

import pandas as pd

from pgmpy.models import DiscreteBayesianNetwork
from pgmpy.estimators import MaximumLikelihoodEstimator
from pgmpy.inference import VariableElimination


# Step 3: Load the Cleveland Heart Disease Dataset

# Method 1: Jupyter Notebook (DEFAULT)

url = "https://archive.ics.uci.edu/ml/machine-learning-databases/heart-disease/processed.cleveland.data"

columns = [
    "age", "sex", "cp", "trestbps", "chol", "fbs",
    "restecg", "thalach", "exang", "oldpeak",
    "slope", "ca", "thal", "heartdisease"
]

df = pd.read_csv(url, names=columns, na_values="?")
df = df.dropna()


# Method 2: Google Colab (ALTERNATIVE)

print("Cleveland Heart Disease Dataset")

print(df.head())

print("\nDataset Shape:")
print(df.shape)

print("\nDataset Information:")
print(df.info())

print("\nColumn Names:")
print(df.columns)

print("\nMissing Values:")
print(df.isnull().sum())


# Step 5: Select required variables

data = df[["cp", "restecg", "heartdisease"]].astype(int)


# Step 6: Create Bayesian Network

model = DiscreteBayesianNetwork([
    ("cp", "heartdisease"),
    ("restecg", "heartdisease")
])


# Step 7: Fit the model using Maximum Likelihood Estimation

estimator = MaximumLikelihoodEstimator(model, data)

for cpd in estimator.get_parameters():
    model.add_cpds(cpd)


# Step 8: Perform inference

infer = VariableElimination(model)


# Step 9: Calculate probability of Heart Disease
# given evidence = restecg

print("Probability of Heart Disease given evidence: restecg")

print(infer.query(
    variables=["heartdisease"],
    evidence={"restecg": 1}
))


# Step 10: Calculate probability of Heart Disease
# given evidence = cp

print("\nProbability of Heart Disease given evidence: cp")

print(infer.query(
    variables=["heartdisease"],
    evidence={"cp": 2}
))

## 3. Theory and Important Concepts

- Bayesian Network: It is a probabilistic graphical model that represents relationships between variables using a directed acyclic graph (DAG).
- Directed Acyclic Graph (DAG): A graph containing directed edges without any circular path.
- Nodes: Represent random variables such as chest pain, resting ECG and heart disease.
- Edges: Represent conditional dependencies between variables.
- Conditional Probability: It represents the probability of an event occurring when another event is already known.
- Conditional Probability Table (CPT): Stores the probabilities of a variable for different combinations of its parent variables.
- Bayesian Inference: It calculates the probability of an unknown variable using available evidence.
- Maximum Likelihood Estimation (MLE): Estimates probabilities from observed dataset values by calculating their frequency.
- Variable Elimination: An inference technique that calculates probabilities by eliminating unnecessary variables from the network.
- Evidence: Known information provided to calculate the probability of another variable.
- Cleveland Heart Disease Dataset: A medical dataset containing patient information and attributes related to heart disease.

Important Dataset Attributes Used:

- cp: Represents chest pain type.
- restecg: Represents resting electrocardiographic results.
- heartdisease: Represents the heart disease diagnosis or severity level.

Bayesian Network Structure:

- cp → heartdisease
- restecg → heartdisease

Here:
- Chest pain type and resting ECG are parent nodes.
- Heart disease is the child node.
- Both medical attributes influence the probability distribution of heart disease.

Important Formula:

Bayes' Theorem:

P(A|B) = P(B|A) × P(A) / P(B)

- P(A|B): Probability of event A given evidence B.
- P(B|A): Probability of evidence B when event A occurs.
- P(A): Prior probability of event A.
- P(B): Probability of the evidence.

The Bayesian Network uses conditional probability distributions to calculate the probability of heart disease based on the available evidence.

## 6. Important Formulas and Calculations

### Bayes' Theorem

P(A|B) = P(B|A) × P(A) / P(B)

- P(A|B) represents the probability of heart disease given medical evidence.
- P(B|A) represents the probability of observing the medical evidence when heart disease is present.
- P(A) represents the prior probability of heart disease.
- P(B) represents the probability of the observed evidence.

### Maximum Likelihood Estimation

P(X = x) = Count(X = x) / Total Observations

- Count(X = x) represents the number of times a particular value occurs.
- Total Observations represents the total number of records.
- MLE estimates probabilities using the frequency of values in the dataset.

### Conditional Probability

P(Heart Disease | cp, restecg)

- Represents the probability of heart disease given chest pain type and resting ECG.
- The Bayesian Network uses conditional probability distributions to represent these relationships.

Note:
- The program uses MLE to estimate the probability distributions and Variable Elimination to calculate the required probabilities.
- The code performs two separate inference queries using different evidence variables.
