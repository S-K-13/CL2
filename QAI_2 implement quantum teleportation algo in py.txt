# Step 2: Import required libraries
from qiskit import QuantumCircuit
from qiskit_aer import AerSimulator
from qiskit.visualization import plot_histogram
from IPython.display import display


# Step 3: Create a quantum circuit with 3 qubits and 3 classical bits
circuit = QuantumCircuit(3, 3)


# Step 4: Apply X gate on qubit 0
# This initializes qubit 0 in state |1>
circuit.x(0)

# Add barrier to separate operations
circuit.barrier()


# Step 5: Create entanglement between qubits 1 and 2

# Apply Hadamard gate on qubit 1
circuit.h(1)

# Apply CNOT gate between qubits 1 and 2
circuit.cx(1, 2)


# Step 6: Apply CNOT gate between qubits 0 and 1
circuit.cx(0, 1)

# Apply Hadamard gate on qubit 0
circuit.h(0)

# Add barrier
circuit.barrier()


# Step 7: Measure qubits 0 and 1
# Store results in classical bits 0 and 1
circuit.measure([0, 1], [0, 1])


# Step 8: Apply correction gates to qubit 2

# Add barrier before correction operations
circuit.barrier()

# Apply controlled X gate
circuit.cx(1, 2)

# Apply controlled Z gate
circuit.cz(0, 2)


# Step 9: Measure qubit 2
circuit.measure(2, 2)


# Step 10: Display the quantum circuit
display(circuit.draw(output='mpl'))

# Display quantum circuit in plain text format
print(circuit.draw())

# Step 11: Initialize the quantum simulator
simulator = AerSimulator()


# Step 12: Execute the circuit with 1000 shots
job = simulator.run(circuit, shots=1000)

# Get the execution result
result = job.result()

# Extract measurement counts
counts = result.get_counts(circuit)


# Step 13: Display the measurement results
print("Quantum Teleportation Results:")
print(counts)


# Step 14: Display the histogram
display(plot_histogram(counts))

## 3. Theory and Important Quantum Concepts

1. Quantum Teleportation:
   - It is a process of transferring an unknown quantum state from one qubit to another using entanglement and classical measurement results.
   - The original state is not physically transported, and the sender cannot retain a copy of it.

2. Qubit:
   - A qubit is the basic unit of quantum information.
   - It can exist in state |0>, |1>, or a superposition of both.

3. Quantum Entanglement:
   - Entanglement is a quantum phenomenon in which two qubits become strongly correlated.
   - Measuring one entangled qubit provides information about the other qubit.

4. Bell State:
   - A Bell state is a maximally entangled two-qubit state.
   - It is created using a Hadamard gate followed by a CNOT gate.

   Formula:

   |Φ+> = (|00> + |11>) / √2

5. Superposition:
   - A qubit exists as a combination of |0> and |1> until measurement.
   - The Hadamard gate is used to create superposition.

6. No-Cloning Theorem:
   - It states that an arbitrary unknown quantum state cannot be copied perfectly.
   - Quantum teleportation transfers the state without creating a duplicate.

7. Quantum Measurement:
   - Measurement converts quantum information into classical information.
   - It collapses a qubit into either |0> or |1>.

8. Classical Communication:
   - The sender measures two qubits and obtains two classical bits.
   - These measurement results are used to apply correction operations to the receiver's qubit.

- `circuit.x(0)` applies the Pauli-X gate to qubit 0.
- It changes the initial state from |0> to |1>.
- This initializes the quantum state that will be teleported.

### Step 5: Create Entanglement Between Qubits 1 and 2

- `circuit.h(1)` applies a Hadamard gate to qubit 1.
- `circuit.cx(1, 2)` applies a CNOT gate with qubit 1 as control and qubit 2 as target.

### Step 6: Apply CNOT and Hadamard Gates

- `circuit.cx(0, 1)` applies a CNOT gate between qubits 0 and 1.

- `circuit.measure([0, 1], [0, 1])` measures qubits 0 and 1.

- These two measurement outcomes determine the correction operations.

### Step 8: Apply Correction Gates to Qubit 2

- `circuit.cx(1, 2)` applies a controlled-X gate.
- `circuit.cz(0, 2)` applies a controlled-Z gate.
- These gates use the measured qubits as controls to correct the state of qubit 2.
- This allows qubit 2 to recover the original state.

### Step 9: Measure Qubit 2

- `circuit.measure(2, 2)` measures the receiver's qubit.
- The result is stored in classical bit 2.
- This allows us to verify the final teleported state.

- `simulator.run(circuit, shots=1000)` executes the circuit 1000 times.
- `job.result()` retrieves the execution results.
- `result.get_counts(circuit)` extracts the measurement outcomes and their frequencies.

### Step 13: Display Measurement Results

- `print(counts)` displays the measurement outcomes and their frequencies.

## 6. Quantum Gates and Operations Used

### 1. Pauli-X Gate (X)

- Acts like a quantum NOT gate.
- Converts |0> into |1> and |1> into |0>.

Matrix:

X = [[0, 1], [1, 0]]

Used to initialize qubit 0 in state |1>.

### 2. Hadamard Gate (H)

- Creates superposition in a qubit.
- Converts |0> into |+>.

Matrix:

H = 1/√2 × [[1, 1], [1, -1]]

Used to create entanglement and prepare qubit 0 for measurement.

### 3. CNOT Gate (CX)

- A two-qubit controlled gate.
- Flips the target qubit when the control qubit is |1>.

Used to create the Bell pair and perform correction on qubit 2.

### 4. Controlled-Z Gate (CZ)

- Applies a phase flip when both control and target qubits are |1>.
- Changes the phase of the |11> component.

Used to perform the final correction on qubit 2.

### 5. Measurement

- Converts quantum states into classical bits.
- Used to obtain the teleportation measurement results.
