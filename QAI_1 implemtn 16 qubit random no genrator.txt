# Step 2: Import required libraries
from qiskit import QuantumRegister, ClassicalRegister, QuantumCircuit
from qiskit_aer import AerSimulator
from IPython.display import display


# Step 3: Initialize quantum and classical registers

# Create a quantum register containing 16 qubits
q = QuantumRegister(16, 'q')

# Create a classical register containing 16 bits
c = ClassicalRegister(16, 'c')


# Step 4: Create the quantum circuit
circuit = QuantumCircuit(q, c)


# Step 5: Apply Hadamard gate to all 16 qubits
# This puts all qubits into superposition
circuit.h(q)


# Step 6: Measure all qubits
# Store measurement results in classical bits
circuit.measure(q, c)


# Step 7: Display the quantum circuit

# Display circuit in graphical format
display(circuit.draw(output='mpl'))

# Display circuit in text format
print(circuit.draw())


# Step 8: Initialize the quantum simulator
backend = AerSimulator()


# Step 9: Execute the circuit with one shot
print("Executing Job...\n")

job = backend.run(circuit, shots=1)

# Get the execution result
result = job.result()

# Extract measurement counts
counts = result.get_counts(circuit)


# Step 10: Display the generated random number
print("RESULT:", counts)

# Display the 16-bit random number
random_number = list(counts.keys())[0]

print("\n16 Qubit Random Number:", random_number)

print("\nProgram Executed Successfully!")

## 3. Theory and Important Quantum Concepts

1. Qubit:
   - A qubit is the basic unit of quantum information.
   - It can exist in state |0>, |1>, or a superposition of both.

2. Superposition:
   - A qubit can exist in a combination of |0> and |1> until measurement.
   - In this practical, each qubit has an equal probability of producing 0 or 1.

3. Hadamard Gate (H):
   - Creates an equal superposition of |0> and |1>.
   - Converts |0> into |+> and |1> into |->.

   Formula:

   |+> = (|0> + |1>) / √2

   Matrix:

   H = 1/√2 × [[1, 1], [1, -1]]

4. Quantum Register:
   - A collection of qubits used to store quantum information.
   - This practical uses 16 qubits.

5. Classical Register:
   - Stores measurement results obtained from quantum qubits.
   - This practical uses 16 classical bits.

6. Quantum Circuit:
   - A sequence of quantum gates and operations applied to qubits.
   - Here, it contains Hadamard gates and measurement operations.

7. Quantum Measurement:
   - Converts a quantum state into a classical result (0 or 1).
   - Measurement collapses the superposition into one of the possible states.

8. Quantum Random Number Generation:
   - Each qubit has a 50% probability of producing 0 or 1.
   - Measuring 16 qubits generates a random 16-bit binary number.

   Total possible combinations = 2^16 = 65,536.
