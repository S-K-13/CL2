# Step 2: Import required libraries
from qiskit import QuantumRegister, ClassicalRegister, QuantumCircuit, transpile
from qiskit.circuit.library import QFTGate
from qiskit_aer import AerSimulator
from IPython.display import display


# Step 3: Create 5 quantum bits and 5 classical bits
q = QuantumRegister(5, 'q')
c = ClassicalRegister(5, 'c')

circuit = QuantumCircuit(q, c)


# Step 4: Prepare the input quantum state
circuit.x(q[4])
circuit.x(q[2])
circuit.x(q[0])


# Step 5: Apply the 5-qubit Quantum Fourier Transform
qft = QFTGate(5)

circuit.compose(qft, qubits=q, inplace=True)


# Step 6: Measure all qubits
circuit.measure(q, c)


# Step 7: Display the quantum circuit
display(circuit.draw(output='mpl'))

# Display circuit in text format
print(circuit.draw())


# Step 8: Simulate the quantum circuit
backend = AerSimulator()

transpiled_circuit = transpile(circuit, backend)

job = backend.run(transpiled_circuit, shots=1000)

result = job.result()


# Step 9: Get and display measurement results
counts = result.get_counts(transpiled_circuit)

print("\nQFT Output:")

for key, value in counts.items():
    print(key, ":", value)

## 3. Theory and Important Quantum Concepts

1. Quantum Fourier Transform (QFT):
   - QFT is a quantum algorithm that transforms a quantum state from the computational basis into the Fourier basis.
   - It uses Hadamard gates and controlled phase rotation gates.

2. Computational Basis:
   - The standard quantum states represented by |0> and |1>.
   - A multi-qubit system can represent binary states such as |00000> and |10101>.

3. Fourier Basis:
   - It represents quantum states using different phase relationships.
   - QFT transforms the input state into this basis.

4. Superposition:
   - A qubit can exist in a combination of |0> and |1>.
   - Hadamard gates help create superposition during QFT.

5. Phase Rotation:
   - Phase rotation gates change the phase of a quantum state.
   - Controlled phase rotations are used to perform the Fourier transformation.

6. Swap Operation:
   - Swap gates exchange the states of two qubits.
   - They are used in QFT to arrange the output qubits in the correct order.

7. Inverse QFT:
   - It reverses the operations performed by QFT.
   - It is used to recover the original quantum information.

Important Formula:

QFT |x> = (1/√N) Σ e^(2πixy/N) |y>

Where:
- N = 2^n, the total number of possible states.
- x = Input state.
- y = Output state.
- n = Number of qubits.

For 5 qubits:

N = 2^5 = 32

Therefore, 32 computational basis states are possible.

Matrix:

X = [[0, 1], [1, 0]]

Used to prepare the input state |10101>.

- Converts a quantum state from the computational basis into the Fourier basis.
- Uses Hadamard gates and controlled phase rotations internally.
- In this practical, it is applied using `QFTGate(5)`.

### 3. Controlled Phase Rotation

- Changes the phase of a target qubit depending on the control qubit.
- It is an important operation used internally in QFT.

### 4. Swap Gate

- Exchanges the states of two qubits.
- Used in the standard QFT circuit to arrange qubit order when required.
