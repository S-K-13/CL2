# Step 2: Import required libraries

import nltk

from nltk.tokenize import sent_tokenize, word_tokenize
from nltk.corpus import stopwords
from nltk.stem import PorterStemmer, WordNetLemmatizer


# Step 3: Download required NLTK resources

nltk.download('punkt')
nltk.download('punkt_tab')
nltk.download('stopwords')
nltk.download('wordnet')
nltk.download('averaged_perceptron_tagger_eng')


# Step 4: Input text document

text = """Information retrieval is an important
field of computer science.
Students are learning different techniques
for retrieving useful information.
They are studying preprocessing and processing."""


print("Original Text:")
print(text)


# Step 5: Sentence Segmentation

sentences = sent_tokenize(text)

print("\nSentence Segmentation:")
print(sentences)


# Step 6: Tokenization

words = word_tokenize(text)

print("\nWord Tokenization:")
print(words)


# Step 7: Convert text into lowercase

words = []

for word in word_tokenize(text):
    words.append(word.lower())

print("\nLowercase Words:")
print(words)


# Step 8: Remove Stop Words

stop_words = set(stopwords.words('english'))

filtered_words = []

for word in words:
    if word.isalpha() and word not in stop_words:
        filtered_words.append(word)

print("\nAfter Stop Word Removal:")
print(filtered_words)


# Step 9: Stemming

ps = PorterStemmer()

stemmed_words = []

for word in filtered_words:
    stemmed_words.append(ps.stem(word))

print("\nAfter Stemming:")
print(stemmed_words)


# Step 10: Lemmatization

lemmatizer = WordNetLemmatizer()

lemmatized_words = []

for word in filtered_words:
    lemmatized_words.append(lemmatizer.lemmatize(word))

print("\nAfter Lemmatization:")
print(lemmatized_words)

## 3. Theory and Important Concepts

- Text Preprocessing: It is the process of converting raw text into a clean and structured format for further analysis.
- NLP (Natural Language Processing): It enables computers to understand, process and analyze human language.
- Sentence Segmentation: Divides a paragraph into individual sentences.
- Tokenization: Divides text into smaller units called tokens, such as words or sentences.
- Lowercase Conversion: Converts all text into lowercase to maintain uniformity.
- Stop Words: Common words such as is, the, are, and, of that usually carry less importance in information retrieval.
- Stop Word Removal: Removes frequently occurring unnecessary words to reduce text size and improve processing.
- Stemming: Reduces words to their root or base form by removing prefixes or suffixes. Example: learning becomes learn.
- Lemmatization: Converts words into their meaningful dictionary base form. Example: better becomes good when using the appropriate word context and POS.
- Porter Stemmer: An algorithm used to remove common suffixes and reduce words to their stems.
- WordNet Lemmatizer: Uses the WordNet dictionary to convert words into their meaningful base forms.

Difference Between Stemming and Lemmatization:

- Stemming removes word endings using simple rules and may produce non-dictionary words.
- Lemmatization uses vocabulary and linguistic information to produce meaningful dictionary words.
- Example: Studies becomes studi through stemming and study through lemmatization.

### Step 4: Input Text Document

- A multiline text document is stored in the variable `text`.

### Step 5: Sentence Segmentation

- `sent_tokenize(text)` divides the input paragraph into individual sentences.
- The sentences are stored in the `sentences` variable.

### Step 6: Tokenization

- `word_tokenize(text)` divides the complete text into individual words and punctuation marks.
- The resulting tokens are stored in the `words` variable.
- This makes further text processing easier.

### Step 7: Convert Text into Lowercase

- An empty list named `words` is created.
- A loop processes each token generated by `word_tokenize()`.
- `word.lower()` converts every token into lowercase.
- The converted words are stored using `append()`.

### Step 8: Remove Stop Words

- `stopwords.words('english')` retrieves the predefined English stop word list.
- `set()` stores the stop words in a set for efficient membership checking.
- An empty list named `filtered_words` is created.
- `word.isalpha()` checks whether a token contains only alphabetic characters.
- `word not in stop_words` checks whether the word is not a stop word.
- Only meaningful alphabetic words are stored in `filtered_words`.

### Step 9: Stemming

- `PorterStemmer()` creates a Porter Stemmer object.
- An empty list named `stemmed_words` is created.
- A loop processes each filtered word.
- `ps.stem(word)` removes common word endings to generate word stems.
- The resulting stems are stored in `stemmed_words`.

### Step 10: Lemmatization

- `WordNetLemmatizer()` creates a lemmatizer object.
- An empty list named `lemmatized_words` is created.
- A loop processes each filtered word.
- `lemmatizer.lemmatize(word)` converts words into their dictionary base forms.
- The resulting words are stored in `lemmatized_words`.

Note: The lemmatizer uses noun as its default POS. Therefore, some verbs may not be converted into their expected base forms.
